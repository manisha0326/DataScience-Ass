# Machine Learning Assignment

## Questions

1. Train linear regression on a dataset. Show where it fails. Apply polynomial
   regression and compare results using plots. Write a short explanation.
2. Train logistic regression on a binary dataset. Plot decision boundary. Show
   predicted probabilities. Explain why logistic regression is suitable for
   classification.
3. Train multi-class logistic regression on the Iris dataset. Report accuracy and
   confusion matrix. Visualize prediction confidence. Explain model performance.
4. Apply k-means clustering on a 2D dataset. Experiment with different values of K.
   Visualize clusters and centroids. Explain how K affects clustering.
